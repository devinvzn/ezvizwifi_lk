EZVIZ WIFI LK — COMPLETE WEBSITE UPLOAD PACKAGE

UPLOAD LOCATION
Extract this ZIP and upload ALL files and folders directly into the GitHub repository root.
Hostinger Git deployment Root Directory should remain: public_html.
Do not upload this package inside a nested public_html/ or ezviz_homepage/ folder.

INCLUDED
- index.html — Homepage with 6-slide automatic campaign banner slider (5-second interval)
- products.html — Product catalogue
- product.html — Product details template
- cart.html — Shopping cart
- checkout.html — WhatsApp order-request checkout
- smart-home.html — Smart home information
- support.html — Support and FAQs
- contact.html — Contact information
- battery-cameras.html — Battery camera landing page
- products.json — 68-product catalogue and contact settings
- img/n01.jpg through img/n68.jpg — product images
- images/ — feature artwork and six supplied homepage banners
- assets/ — shared CSS, logo and favicon
- js/app.js — shared website functionality

FUNCTIONAL NOTES
- Product prices are blank where not supplied; no prices have been invented.
- Checkout sends an order request through WhatsApp. No card payment gateway, order database, stock synchronisation or admin panel is connected.
- Product information should be checked against current official EZVIZ product information before publishing.
- This is an independent Sri Lankan product website, not the EZVIZ corporate global website.

DEPLOYMENT
1. Replace the repository contents with the contents of this ZIP (files at repository root).
2. Commit the upload to main.
3. Hostinger should deploy from branch main with deployment directory public_html.
4. Check deployment status in hPanel, then test the live website.
5. If the domain still returns 403, check Hostinger deployment logs, file permissions and that index.html exists directly inside public_html.

This package has not been deployed from this file-generation step.
